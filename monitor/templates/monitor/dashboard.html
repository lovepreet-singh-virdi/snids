Quick How-To (no coding)

  • Go to Monitoring, pick your network (Loopback or Wi‑Fi), click Start.
  • Want instant data? Upload the sample file in Monitoring → PCAP (choose pcaps/ETH_IPv4_TCP_syn.pcap), then watch the Dashboard update.
  • When finished, click Stop (or End All Active Sessions if something got stuck).
  • Need a quick demo script (optional, Windows admin shell): run python scripts\simulate_syn_flood.py to generate alerts.

What the cards/charts tell you

  • Totals: packets, TCP subset, total alerts.
  • Alerts by Type/Severity: mix of detections and criticality.
  • TCP Flags: SYN/RST spikes hint at flood/reset storms.
  • Packet Rate: traffic volume trend (10 minutes).
  • Top IPs / Recent Alerts: quickest triage targets.
