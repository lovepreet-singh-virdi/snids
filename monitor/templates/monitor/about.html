About & Architecture

Smart Network Intrusion Detection System (SNIDS) monitors TCP traffic, detects SYN floods, TCP reset spikes, and session anomaly indicators using rule-based logic. It supports live capture (Scapy) and offline PCAP analysis.

Flow
Packet (live/pcap) -> Feature Extraction (TCP fields, counters) -> Detection Engine (rules) -> Alerts -> DB (SQLite) -> Django Views/API -> Dashboard (Bootstrap + Chart.js)
Modules
  • Packet Capture: Scapy live sniff or PCAP parsing
  • Feature Extraction: TCP flags, seq/ack, per-flow counters
  • Detection Engine: SYN flood, RST spike/flow anomaly, session hijack indicators (seq jump, duplicate ACK)
  • Alert Manager: cooldown/dedup, severity
  • Storage: PacketLog, SecurityAlert, MonitoringSession
  • UI: Dashboard, Alerts, Traffic, Monitoring, Settings
Demo Tips
  1. Start live monitoring on loopback/ethernet.
  2. Run simulation scripts (SYN, RST, anomaly).
  3. Show alerts, charts, and packet logs updating.
  4. Upload a PCAP to demonstrate offline analysis.
Detection Rules (brief)
  • SYN Flood: SYN rate per source, low handshake completion ratio -> severity scaled by intensity.
  • TCP Reset Spike: RST bursts per source and per flow.
  • Session Anomaly: large sequence jumps; repeated duplicate ACKs.
